# Jett benchmark subset v0.5.4

The implemented language surface, tasks, adapters, and compiler contract are
unchanged from `jett_subset_v0.5.3.md`. Version 0.5.4 changes only the
serialized Jett programming-skill reference used by `skill_assisted` rows.

The skill remains general-purpose and may document implemented public Jett
behavior. It contains no benchmark task, fixture, hidden grader, observed
solution, or task-specific repair recipe. Proposed behavior in
`docs/open_design/` remains outside the implemented subset.
