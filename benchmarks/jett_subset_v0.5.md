# Jett benchmark subset v0.5

The Jett language surface is unchanged from `jett_subset_v0.4.md`. Version 0.5
changes the context treatment, not the programming tasks or compiler contract.

The Jett skill may document any implemented, public Jett behavior because it is
intended to support ordinary Jett programming beyond the benchmark. A benchmark
submission must still remain within the required declaration and task
constraints. Proposed behavior from `docs/open_design/` is not part of the
implemented subset.
