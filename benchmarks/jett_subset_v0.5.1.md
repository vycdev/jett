# Jett benchmark subset v0.5.1

The implemented Jett language surface, tasks, adapters, and compiler contract
are unchanged from `jett_subset_v0.5.md`. Version 0.5.1 changes only the
serialized Jett programming-skill reference used by the `skill_assisted`
context treatment.

The skill may document any implemented, public Jett behavior because it is
intended for ordinary Jett programming beyond the benchmark. A benchmark
submission must still remain within the requested declarations and task
constraints. Proposed behavior in `docs/open_design/` remains outside the
implemented subset.
