## Constructor-owned transport

Fresh Resource CFG analysis admits only a structurally proven Resource-free
consuming `list` operand with one exact ordinary element binder, or an ordinary
Resource-free enum discriminant with distinct checked variant payload binders
and the original exhaustive edges. Resource operations in their bodies retain
their independent custody plan; the iterable, binder and discriminant do not
create a Resource owner or loan.

Sequence preparation validates the complete before-witness, then reconstructs
the finite canonical edit itself. It appends exactly three temporary headers in
cursor, length, source order; initializes source, cursor zero and length at the
unique original preheader; prefixes the body with consuming element extraction
then cursor increment; and replaces `ForEach` with `cursor < length` using its
original body and exit edges. Exact types, spans, header metadata, statement
order and the entire resulting graph must match. Added blocks, redirected edges
or an otherwise convincing edit transcript cannot grant authority.

Only after that equality check may the two-statement body prefix advance current
borrowed-projection, lexical-exit and normalized-call sites. Independent
original/current association seals and descriptor-body checks remain required.
The archival declaration, initializer, backing and Source facts stay distinct
from current sites. Consecutive or nested normalization must validate each
finite transition; a preceding successful edit grants no general rewrite
authority. Duplicated, missing, moved, retargeted or independently resealed
projections/exits fail, including before canonical pruning. Preparation without
another edit preserves every witness.

Existing strict joins are unchanged: operation stacks, arrived prefixes,
retirement obligations and leases must agree, and a moved/uninitialized versus
live owner still requires its own conditional cleanup proof. Certified lexical
exits end child payload loans before parent shell loans and clear only their
nonowning aliases, preserving the backing for its later owning use. Final native
codegen still refuses a raw, unprepared `ForEach`.
