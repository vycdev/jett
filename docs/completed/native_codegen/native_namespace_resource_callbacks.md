# Namespace-qualified Resource callbacks

A namespace-qualified function value must select its exact resolved declaration
and retained checked body, just like an unqualified named function. The original
call remains indirect. Namespace members resolve at the whole expression span;
field spelling or a matching function signature cannot grant that authority.
Instance fields, method adapters and compiler hooks need their own transport and
must not enter this named-body path merely because they use dotted syntax.

The genuine shared Source programs initialize an immutable callback from
`resource_probe.close`, then call it directly or through an immutable alias.
The shared corpus grows from 28 to 32 scenarios: successful close, handled factory
failure, finalizer failure and alias close. Both profiles require exact events,
separate body/cleanup reports, Source-absent native launch and zero obligations
before teardown. The baseline reference gate fails on the first qualified
callback with `resource value lost its checked payload custody`. The actual
native gate passes all 64 executions. A corrected test filter selects the one
shared Resource group; an earlier zero-test invocation is excluded. Runtime
sources and measured archives are unchanged.

This closes one existing callable provenance seam. Returned hook descriptors,
dynamic/captured/scoped/generic/handled/pipeline callbacks, aggregate Resource
ownership, production providers and scheduling remain in the full goal.

## Verified reference and native execution

Reference proof now admits the original qualified producer only through its
full-span resolved Function definition, unique retained non-generic header and
exact checked Function signature. The original expression occurrence, body
attempt, immutable alias chain and indirect invocation packet remain checked.
Member spelling and runtime function names cannot supply body authority.

All seven named-callable proof tests and all 515 reference-library tests pass,
including all 64 shared Resource executions. Genuine instance-field, method-value,
generic and compiler-hook controls cannot mint named-body proof. Copied, foreign,
same-signature target, signature and producer-as-invocation substitutions fail.
The final linked native gate passes all 64 executions with Source absent and zero
obligations before teardown. The complete driver library also passes 92 tests.
Fresh supported-host acceptance remains a separate gate. The broad native-language estimate stays about 85%.
