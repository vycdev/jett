## Required private proof

Use one exhaustive original-body declaration inventory over lexical blocks and
handler failure bodies, without entering a separate inline callable body. Each
borrowed alias key retains the original function/archive, declaration LocalId,
immutable local headers, complete initializer, exact backing local and lexical
path. Match the complete expected key set bijectively; an equal row count or an
expression/span lookup is insufficient. Canonical remaps may update current
headers and sites only after validating the independent original/current body
seal. They cannot rewrite the original occurrence or manufacture authority.

Only exact authenticated borrowed alias declarations may cross the current
nested-declaration refusal. Nested owning declarations and unrelated view locals
retain their own conservative admission rules. Child payload loans end before
parent shell loans, and generated alias/source/output state is retired at the
actual lexical exit before a branch join or loop backedge. Runtime reissue at
the same static row must receive fresh dynamic loan handles.

Authenticate Fallthrough, Return, Break and Continue independently. A Return
operand that observes its alias must be evaluated before that alias retires;
abandoned argument-prefix cleanup retains its existing separate ordering.
For/Match/reflected bodies and declarations after a terminal Return remain
full-goal obligations unless actual original Source and constructor exit proofs
cover them. A recursive visitor alone cannot claim execution support or erase an
unemitted occurrence as permission.

## Acceptance

Freeze the full Source-only packet and production hashes, pass every real
reference execution, then implement the constructor/MIR/codegen handoff. Require
negative controls for sibling/backing swaps, duplicate/missing keys, altered
headers/initializers/guards/exit membership, foreign archives, copied or
independently resealed/pruned bodies, and disconnected extraction. Run all shared
sources in both native profiles with exact scripts, outcomes and event ordering,
Source absent at launch, and zero ordinary/Resource obligations before teardown.

The existing runtime can end and reissue a loan at the same static operation;
logical lexical retirement alone requires no ABI/schema change. Runtime changes
would instead require fresh independently measured archives and a new pinned
receipt. Inactive loan history grows across iterations even when live obligations
are zero; this existing storage behavior is separate from lexical correctness.
GNU private execution and current coherent workspace/package/installed gates
remain independent acceptance requirements.
