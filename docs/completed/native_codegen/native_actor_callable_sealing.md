# Initial actor reflected callable sealing

This bounded transition handles initial checked lowering when a real reflected
field getter occurs directly in an actor handler or constructor. Actor snapshots
are already sealed when the actual callable producer replaces bound plan tokens.
Their renewal must derive from that same actual output, preserving all checked
actor receipts, target ordinals, role facts and persistent-view projections.

The sole CheckedCallableSealing receipt remains the actual token authority. Its
complete before/output Programs, archive identities, checked Arc, borrowed type
arena, raw source epoch and recorded optional getter/adapter edits are unchanged.
The native baked.current renewal also remains unchanged. An ordinary getter's
real empty adapter slot is recorded by that shared producer as None to Some of
the same sealed getter token; the actor transition does not reconstruct tokens.

A private original-Lowerer context may derive an opaque actor renewal from the
retained output. It authenticates the entire token output, full original actor
inventories and snapshots, exact checked Arc/type arena and complete empty initial
archive before changing snapshot fields. An empty archive alone supplies no
admission. A normal later actor-changing seal refuses until its producer path is
represented. With no actor delta, the shared existing peer flow stays unchanged.

An actual actor delta with temporary-owner markers may proceed only through the
separate original-construction, BEFORE-value-only finalization path. It retains
every marker and complete Source certificate, proves an exact finite earlier-
declaration dependency closure, and fills each original cell once before the
actor epoch's retained after table exists. Changed canonical producers and later
unrepresented compositions still refuse as compiler gaps, never checker/source-
validity rules. No combined Source cycle is claimed from structural reasoning.
The separate unchanged Packet projection control now requires genuine lowering
and full archive/backend/epoch validation; its new native proof is a separate
measurement. See [the temporary finalization note](native_actor_temporary_owner_finalization.md).

The protected actor stage must remain exact after existing initial peers. The
original finalizer runs the existing initial sum sealer once on that retained
stage and validates full actor/sum receipts. One private epoch then retains the
raw predecessor source Arc and complete final table before attaching its edge to
changed entries/views. The stored tables contain no new edge, and sealed plans
refer only to the raw predecessor. This forms a finite immutable graph; actual
Weak expiry controls remain required rather than inferring lifetime from exit.

Ordinary Seal.sources retains the same raw pre-seal Arc as the actual receipt;
existing outer callable canonicalization happens during comparison. Source
matching retains full actor metadata. If ordinary exact matching does not suffice,
it uses only existing protected original/baked/Graph/required restoration to reach
a represented checkpoint, authenticates current actor/sum/archive gates and the
exact source epoch/checked identities, then compares the complete restored table
to that edge's private actual checkpoint. Only after that proof may a non-executable
comparison view restore historical actor metadata for affected entries. Outer
operations, headers, siblings, functions and peer inventories remain exact.

The view cannot grant Source-call, Generated, Resource, provider or actor-entry
permissions. It never overwrites historical sources with a current table, erases
actor roles or searches arbitrary ancestors. Graph conversion_sources remains its
separate private recipe. Later actor edges, unsupported appended-function epochs
or canonical/bake/Graph/Resource compositions without an exact represented path
continue to refuse explicitly.
