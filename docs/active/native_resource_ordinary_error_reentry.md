dynamic message and diagnostic prefix, issued by the exact Resource entry
constructor. Nested calls share the running channel. Legacy session failure and
persistent ordinary cleanup poison remain sticky; historical Resource cleanup
failure keeps its separate accepted reentry behavior. Exact completion/retirement
seals the channel, retains original body and cleanup observations and creates no
error reset. Only an authenticated next constructor can select a fresh channel
after exact predecessor/ordinal, installation, budget and all custody/storage

take a sealed terminal error or provide reentry authority. The private launcher
requests the declared next entry after complete observation; runtime guards decide
admission, and the first nonzero process exit and every completion survive.
No Source syntax, provider API, runtime-global rule or new recovery construct is
introduced. ABI1 and current layout/report protocols need no new export for this
internal lifetime, subject to genuine verification.
