## Exact private transition

Only the existing public checked suite factories derive the wrapper from the
retained immutable checked entry file. A private constructor first authenticates
the complete current function table, unchanged manifest/equality/type meanings,
original checked-program identity, every existing required-value and Graph or
reflected/temporary proof. It appends exactly its locally constructed canonical
wrapper. A retained transition records that complete before program, canonical
wrapper, purpose, entry file, exact checked session, and complete current table.
The original archive.functions() table stays immutable; it is never recaptured
or replaced by the generated wrapper.

Resource required materialization retains the opaque successful required-cache
identity. Property construction joins CheckedPropertyCases to that same checked
session and cache. Preserve every original property's checked trial count and
order; Source17 uses the existing default of 100 generated trials. This protocol
adds no fixed-count Source rule. Replay continues to start from the private pre-suite program, preserving
its original trial identities and checked changed-input validation.

The transition issues one opaque suite-call receipt per canonical wrapper
invocation, with a one-based preorder expression ordinal across the whole
original wrapper. This includes PropertyCaseContext and argument expressions;
identical argument values in different trials do not collapse their identity.
Each receipt retains the whole suite origin and exact invocation tuple. A public
GeneratedOperation::NativeSuite packet, equal spelling, copied current function,
or caller-owned case vector cannot mint the receipt. Later canonical conversion
may renew a complete current view only after its complete input is authenticated.
All peer Graph, reflected, mutable-sum, actor and temporary transitions must first
validate the same unchanged-before archive before their renewed views are joined.

existing Source-certified edges. This is a distinct private native-suite bridge,
not a fabricated SourceCallOwnership and not a general Generated exception.

through that separate role. Pure suite wrappers have zero Network parameters;

Potential Resource paths stay
in the full original type graph even when selected values contain no live leaves.
All transitive helper calls keep their original Source certificates, typed carrier
plans and cleanup. No hook, provider grant or occupied Resource custody is minted.

## Contextual extraction inside checked bodies

A direct helper call can belong to the retained Resource execution family even
when every actual and the result have ordinary types. Endpoint types alone do
not prove that the call may stay embedded inside an ordinary expression. The
Builder now includes such exact calls in its contextual extraction predicate:
the retained execution closure must recognize the original direct call, the
Source packet must retain its original actuals, and all endpoints admitted by
this added ordinary path must be free of pending Resource transport. Matching
names, a nonempty manifest or an ordinary return type cannot supply this proof.

Existing eager operand and ordered-container lowering propagates that predicate
through its established traversal. It stages earlier values before lowering a
later nested call, preserves the checked argument/field permutation and invokes
the helper at its original occurrence. Lists, map entry pairs, record fields,
interpolations and ordinary call/intrinsic operands reuse their existing
ordinary-staging eligibility checks; this is not a blanket promise for every
aggregate shape. Ordinary owning staging still refuses Resource-bearing values
instead of acquiring custody or cloning authority.

Boolean `&&` and `||` retain short-circuit behavior. If the right operand needs
extraction, its call region is built in the selected right-hand CFG branch; it
is not moved ahead of the left test or into the bypass branch. The direct-call
region authenticates the complete unique original tuple before extraction,
then retains Begin/ordered Stage/Invoke/End associations, generated headers and
current sites. A failed region construction restores the Builder checkpoint.
Existing lexical-exit and cleanup proofs remain required.

This transport concerns calls inside original checked bodies. The canonical
generated suite wrapper still has its separate exact flat context/call protocol
and private suite-call receipts. It gains no arbitrary nonflat wrapper, Source
certificate or callable authority from this extraction. Resource-bearing actuals
and results keep their separate carrier transport obligations. Indirect and
resource-hook invocation timing, refinement-handler exit proofs and wider
aggregate/constructor contexts remain pending without new Source prohibitions.
